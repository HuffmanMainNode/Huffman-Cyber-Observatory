# Security Policy

## Supported versions
Only the latest `main` branch is currently supported. No stable release series has been declared.

## Reporting
Do not publish exploitable details in a public issue. Use GitHub private vulnerability reporting if enabled. Otherwise contact the repository owner through a verified channel on the GitHub profile.

Include affected commit, impact, reproduction conditions, and mitigation. Never include live credentials, private keys, or personal data.

## Scope and guarantees
- Read-only by default; no exploit execution.
- Secret values must remain redacted in output.
- Network access is limited to explicitly invoked public intelligence retrieval.
- Passing tests are not a security certification.
- Operators are responsible for key custody and secure backups.

Only test systems and data you own or are authorized to assess.
